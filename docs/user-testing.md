# User testing

Usability sessions with people who read Hansard. Each person does the same five tasks on the live site, by screen share or phone, with me watching. This page records when each session ran, who took part, where each person got stuck and what changed because of it.

## Tasks

1. Find something an MP said that you would send to one person you know.
2. Send it to me in the chat app you use.
3. Find out which MP represents the area you live in, and open something they said.
4. You want to quote this paragraph in an article. What would you do first?
5. You think the name above this paragraph is wrong. Show me what you would do.
