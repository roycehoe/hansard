# Corrections

Errors people have reported in the archive, and the fix for each.

## Reporting an error

- Email hansard@fancybinary.sg. The "Report an error" link beside each speech opens an email with that speech's link filled in. Each Report page also has a "Report a problem with this report" link.
- Or open a public issue with the [Report an error form](https://github.com/roycehoe/hansard/issues/new?template=report-an-error.yml).

## What happens next

Royce Hoe runs the site and makes each fix. He fixes an error the archive introduced, in the text or in who it credits, within 7 days of the report. If Parliament asks for a Report to be removed, he commits to taking it off the site within 2 working days, with no reason needed.

Fixes to the stored text or credits go into [roycehoe/hansard-scraper](https://github.com/roycehoe/hansard-scraper), which owns the database. This site only reads it.
