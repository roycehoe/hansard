# Corrections

Errors found in the archive, by an audit or by a reader's report, and the fix for each.

## Reporting an error

- Email contact@openhansard.sg. The "Report an error" action on each paragraph opens an email with that speech's link filled in. Each report page has a "Report an error" link too.
- Or open a public issue with the [Report an error form](https://github.com/roycehoe/hansard/issues/new?template=report-an-error.yml).

## What happens next

I run the site on my own. When the archive gets a speech's words or its speaker wrong, I fix it and add a row to the log below. If Parliament asks me to take a report down, I do it within 2 working days and don't ask for a reason.

Fixes to the stored text or credits go into [roycehoe/hansard-scraper](https://github.com/roycehoe/hansard-scraper), which owns the database. This site only reads it.
