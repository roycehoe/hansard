# 0004. Permanent URLs

Researchers and lawyers cite links, and a citation that stops resolving is worse than an ugly one. The scraper rebuilds its tables often. Its numeric primary keys have changed during dedupes and will change again, and a re-parse can renumber the Speeches in a Report. Numeric IDs would give short URLs that break on the next rebuild. A Report URL is built from the SPRS `report_id`, with the trailing `#` stripped and URL-unsafe characters encoded, for example `/reports/written-answer-16079`. SPRS assigns that ID, and it survives every rebuild. Sittings use their date (`/sittings/1993-04-08`). Persons use `/people/{person_id}-{slug}`. The slug is decorative and a wrong slug redirects. The person ID is the one weak link, because the scraper rebuilds the person table from rules and decisions, so person IDs need to stay stable across rebuilds, or a redirect table has to be added when they move. A Speech has no permanent URL of its own. Its link is the Report URL plus `#s{ordinal}`, and the page says that Speech links are best-effort, because no ID for an individual Speech survives a re-parse.
