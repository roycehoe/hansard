# 0004. Permanent URLs

Researchers and lawyers cite links, and a citation that stops resolving is worse than an ugly one. The scraper rebuilds its tables often. Its numeric primary keys have changed during dedupes and will change again, and a re-parse can renumber the Speeches in a Report. Numeric IDs would give short URLs that break on the next rebuild. A Report URL is built from the SPRS `report_id`, with the trailing `#` stripped and URL-unsafe characters encoded, for example `/reports/written-answer-16079`. SPRS assigns that ID, and it survives every rebuild. Sittings use their date (`/sittings/1993-04-08`). Persons use `/people/{person_id}-{slug}`. The slug is decorative and a wrong slug redirects. The person ID is the one weak link, because the scraper rebuilds the person table from rules and decisions, so person IDs need to stay stable across rebuilds, or a redirect table has to be added when they move. A Speech has no permanent URL of its own. Its link is the Report URL plus `#s{ordinal}`, and the page says that Speech links are best-effort, because no ID for an individual Speech survives a re-parse.

## Amendment, 18 Oct 2026

A Speech gets a link people can share. The launch plan (`plans/launch-q1-launch.md`) makes a Speech permalink, shown as a quote card in chat apps, the main thing the site expects people to share. A `#s{ordinal}` fragment cannot do that job. It never reaches the server, so no preview can name the Speech, and after a rebuild it can point at a different paragraph while the quote in the chat stays the same. The Speech link becomes `/reports/{slug}?s={ordinal}&q={anchor}`, where `anchor` is the paragraph's first 8 words, lowercased. On each visit the server checks that paragraph `ordinal` starts with `anchor`. If it does, the server serves that Speech and builds the preview tags from it. If it doesn't, the server looks for the anchor elsewhere in the Report and serves that paragraph with a note that it moved. If the anchor is gone, the server serves the Report with a note saying so, and the preview carries no quote. The quote in a chat card therefore always matches the page behind it, or the card shows no quote. `#s{ordinal}` keeps working for old links and for scrolling. Report, Sitting and Person URLs do not change. A word in the anchor is a run of letters or digits, so punctuation and formatting marks do not count. When more than one paragraph starts with the anchor, the server picks the one nearest `ordinal`, and the lower ordinal on a tie. A link with no `q`, or a `q` with no words, is not checked and opens the Report. The "Citing and linking" section on /coverage/methods describes the checked link.
