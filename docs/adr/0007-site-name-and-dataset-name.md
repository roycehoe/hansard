# 0007. Site name and dataset name

On 27 October 2026 the website moved to openhansard.sg and took the name Open Hansard. Until then the README banners in both repos read "Singapore Parliamentary Record", and the scraper's README asks anyone who uses the data to cite it as "Royce Hoe (2026). *Singapore Parliamentary Record*. GitHub. https://github.com/roycehoe/hansard-scraper". The website is Open Hansard. The header wordmark, the page titles, the link previews, the OpenAPI title, the basic-auth realm and this repo's README banner all use that name. The dataset in `roycehoe/hansard-scraper` keeps the name Singapore Parliamentary Record, with its banner and its citation, and the scraper's README changes only its links to the website. A citation someone has already copied carries the dataset's name, and renaming the dataset would leave that citation pointing at a name the repo no longer uses. Internal identifiers such as the DigitalOcean app name, the Docker image tag and the `hansard_api` role keep `hansard`, because no visitor sees them.
